Install Golana 1.0

One analog-style synth for the M-VAVE FM-1, laid out like the classic microKORG, with a screen that draws the sound. Installs from this page over USB, in Chrome or Edge. No extra hardware.

Custom firmware, at your own risk. Golana is a fork of Felucca, not made or supported by M-VAVE. It was tested in the computer and in a simulated FM-1; it comes with no warranty.

Safety nets: the firmware can never overwrite the FM-1's boot code. Hold OCT− while switching on for the USB rescue (it also starts by itself after two failed starts), and the official firmware can always be put back from the last card on this page.

Checking the browser…

1Before you start

Tick each box. The Install button stays off until all four are ticked.

2Back up recommended

Saves a file with your projects, sounds, samples and settings to this computer. Nothing is written to the FM-1. It works when the FM-1 runs Felucca, Fantasma or Golana; the official M-VAVE firmware has no backup.

A backup is restored in the editor. Projects do not always move between different firmwares (Felucca, Fantasma, Golana): keep the backup of each.

3The Golana build

Loading the package…

4Connect

Connect the FM-1 by USB and switch it on. Close other programs that use MIDI (a DAW, the editor, another tab). The browser asks to allow MIDI with SysEx: allow it.

Not checked yet.

5Install

Install Golana 1.0

Two steps, both automatic: the FM-1 checks the package and switches to update mode, then writes it and restarts. The page then asks the FM-1 what it runs, to be sure.

If it stops: replug the cable and press Install again. The FM-1 stays in update mode until the write is finished, and the page resumes it. When it says Done, the FM-1 is ready.

If something goes wrong

    
    
      
  1. The install stopped. Replug the USB cable and press Install again: it picks up where it was.
    2. 
      
  2. The FM-1 does not start properly. Switch it off, then on while holding OCT−. It shows
        GOLANA USB RESCUE: no sound, only USB. Come back to this page and press Install.
    3. 
      
  3. The screen stays black and the computer sees a USB device called WL80UBOOT: that is the
        chip's own boot mode. Try another cable and close every MIDI app, then press Install again. Last resort:
        FM-1 Transporter.
    4. 
      
  4. Questions or problems: open an issue.
    5. 
    

  


  

    
Go back to the official firmware

    

      
Return to official V15

      
Download the official FM-1 firmware (FM-1.fwsc, V15) from
        M-VAVE's download page and select the
        unmodified file here. The page checks it in your browser (it is never uploaded) and accepts only V15.
